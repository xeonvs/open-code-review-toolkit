### Locked Decisions

The unlimited product default needs no change. The failed engineering acceptance warning came from an explicit operator cap. Source and controlled-native analysis confirm that OCR 1.13.3 injects the same background into every group and rebuilds round contexts; it does not invoke optional MCP tools automatically. Making all groups submit is not a valid correction, and designating one group alone is insufficient. The chosen narrow correction combines one output owner with an explicit requirement to inspect the global inventory and relevant immutable cross-group diffs, plus closed submission status across rounds. The owner is an executor, not the scope of source data. It must not bulk-request arbitrary/filtered files or infer behavior from other-file metadata alone.

The graph remains a bounded, non-exhaustive description of one coherent changed flow, not a second completeness or finding claim. Actual qualification must inspect the relevant cross-group tool responses and every essential graph transition against the source; a generated state alone is insufficient. No new context subsystem, source-reading tool or Git I/O path is introduced. Native context/compression/tool limits remain explicit reasons to omit optional output, never reasons to call the graph fully qualified without the required source evidence.

Source facts at immutable OCR 1.13.3:

- Selection seals the native reviewed set before semantic grouping; deleted files are retained as context, not reviewed items. Grouping uses path/status/change counts, with no diff content and no MCP tool request; it can fall back to per-file groups and split oversized groups.
- Plan is optional and group-local. Its request has no actual tool definitions; tool documentation appears only as prompt text. There is no guaranteed global plan or final summary-model phase to reuse.
- Main receives full diffs for its own group and metadata for other kept files. It may obtain other file diffs through the shared frozen `file_read_diff` map; `path_array` can request more than one file. That map is built before selection from the same parsed range, so context access must not accidentally preload excluded files.
- Every review round builds new messages. Shared status can prevent repeat submissions, but it does not deliver source context or prove completeness. Native compression can summarize prior tool results; selected-file completion does not establish graph-context coverage.
- Findings aggregate after concurrent subtasks without another model stage. Automatic graph-fragment union, forced single-group reviewing and a new summary-model pass remain outside the approved correction until explicitly reconsidered.
